# KTV Song List Web

[打开点歌台](https://ktv.starfreedomx.top/) · [开始使用](#开始使用) · [投屏与遥控](#投屏与遥控) · [自行部署](#自行部署)

KTV Song List Web 是一个多人在线点歌网页。用手机或电脑打开点歌台，和朋友进入同一个房间，就能一起点歌、调整待唱顺序，并同步查看正在唱、待唱和已唱的歌曲。

## 开始使用

1. 在首页输入房间号，点击「创建房间」。如果朋友已经建好房间，直接打开对方分享的链接，或在首页输入同一房间号并点击「加入房间」。
2. 把房间链接发给一起唱歌的朋友，进房后点击「添加新歌曲」即可点歌。
3. 点好的歌会排到待唱列表末尾，随时可以调整顺序，唱完后切到下一首。

### 点歌

在「添加新歌曲」中搜索歌名或关键词，即可从候选列表里选择视频或分 P。想先试听确认，可以双击搜索结果的标题，直接跳转到 B 站查看。

如果手里已经有 B 站视频，把分享链接或整段分享文案粘贴到「智能提取」即可自动解析（支持普通视频、分 P 和番剧链接），也可以手动填写歌名和链接。提交后弹窗会立即关闭，稍后页面会提示是否添加成功。

选到疑似纯伴奏的版本时，点歌前会弹出确认提示，避免误点。实际是否带人声仍以原视频为准；不需要提醒的话，可以在设置里关闭「伴奏提醒」。

## 投屏与遥控

想在大屏幕上自动连播和切歌，可以搭配配套投屏播放器 [KARAM@S](https://github.com/KARAOKE-MASTER-ZJU/karamas) 使用：

1. [下载并安装 KARAM@S](https://github.com/KARAOKE-MASTER-ZJU/karamas/releases/latest)，在应用的「连接」页填入正在使用的点歌台地址和房间号，加入同一房间。
2. 在 KARAM@S 中选择本机播放、DLNA 投屏或小电视云投屏，播放器会自动跟随当前歌曲并在播完后切歌。
3. 需要用网页控制播放时，先在 KARAM@S 的「设置 → 安全」中开启「网页遥控」，再回到点歌网页底部打开「投屏遥控」，从「投屏 App」列表中选择在线设备。暂停、进度、音量和清晰度等控制项以所选设备实际支持的功能为准。

如果列表里找不到设备，先确认 KARAM@S 仍连在同一个房间、已开启「网页遥控」，且没有切到 HTTP 轮询模式，然后刷新在线列表。更多播放方式与设备连接说明见 [KARAM@S 使用指南](https://github.com/KARAOKE-MASTER-ZJU/karamas#开始使用)。

如果不用投屏客户端，只想让某台手机在切歌时自动打开对应的歌曲链接，可以在那台手机的房间页右上角开启「主机模式」。

## 查找以前的歌单

进入过的房间会自动记录在当前浏览器里。在首页打开「历史房间记录」，点选房间就能查看当时正在唱、待唱和已唱的歌单。历史歌单为只读视图；如果原房间还在有效期内，也可以直接从记录里重新进入。

换设备或清理浏览器数据前，可在「导入 / 导出」里勾选要保留的房间，导出为文本文件或复制到剪贴板，再到新浏览器粘贴导入。导入导出使用的是房间页显示的 UUID（每行一个），与日常加房用的房间号不同。

## 常见问题

### 分享链接提示房间不存在或已失效

房间默认在歌单停止更新约 24 小时后关闭，具体时长由站点部署者设置。你可以在提示页直接用原房间号新建一个房间，或返回首页换别的房间号。新建房间会从空歌单开始，旧歌单仍可从已有历史记录里打开。

### 清理浏览器数据后，历史记录还能找回来吗？

服务器上的历史存档不会随浏览器数据一起删除。只要之前导出过记录，或保留了房间 UUID，随时可以重新导入。同一个房间号之后再次使用，也不会覆盖旧存档。早期没有 UUID 的房间则没有存档。
